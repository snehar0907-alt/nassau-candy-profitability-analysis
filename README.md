# Nassau Candy Distributor — Product Profitability & Margin Analysis

## Project Overview

This project analyzes product-level profitability and gross margin performance for Nassau Candy Distributor. It uses Python for data preparation and exploratory analysis and Streamlit to present interactive business intelligence insights.

## Business Objectives

* Evaluate revenue, cost, gross profit, and gross margin.
* Compare profitability across products and divisions.
* Identify high-revenue products with lower margins.
* Analyze cost behavior and profit concentration.
* Develop data-driven recommendations for management.

## Tools & Technologies

* Python
* Pandas and NumPy
* Matplotlib, Seaborn, and Plotly, where used
* Jupyter Notebook
* Streamlit

## Key Results

* Total Revenue: $141,783.63
* Total Cost: $48,340.83
* Total Gross Profit: $93,442.80
* Overall Gross Margin: 65.91%
* Products Analyzed: 15
* Orders Analyzed: 8,549

## Dashboard Features

* Interactive filters
* Product profitability analysis
* Gross profit and gross margin comparisons
* Division performance
* Cost diagnostics
* Profit concentration analysis
* Margin risk identification
* Management recommendations
* Downloadable analysis results

## How to Run the Project

1. Clone or download this repository.

2. Install the required packages:

   `pip install -r requirements.txt`

3. Open a terminal in the project folder.

4. Run the dashboard:

   `streamlit run app.py`

## Project Files

* `app.py` — Streamlit dashboard
* `Nassau_Candy_Profitability_Analysis.ipynb` — analytical notebook
* CSV files — source data and analysis outputs
* `requirements.txt` — Python dependencies
